# Judge-Friendly Demo Script (2–3 minutes)

1. Open the app. Point out the synthetic-data notice and interactive force-directed graph (Cytoscape.js).
2. Click **Play Scenario**.  
   - Shows risk-weighted blast radius from Laptop-07.  
   - Then shortest path to Payroll DB.  
   - Then containment suggestions with operational-impact notes and caveats.
3. Explain the risk score: `(criticality_score × avg_edge_weight) / hops`. Emphasize it is an illustrative prioritization aid, not a probability.
4. Show one containment suggestion and the explicit “does not guarantee containment” caveat.
5. Optionally toggle Directed mode or set After time = 09:20 and re-run to show filters.
6. Scroll to alerts and note entity correlation.
7. Close by restating: all data is synthetic; this is an educational prototype, not production-ready.

Key talking points: transparency of scoring, honest limitations, interactive visualization, structural containment analysis.
